Emergency procedures

Recognizes the squawk.
Changes the response.

Set the code on your active transponder. The add-on acknowledges it once and pauses routine assigned-code reminders while it remains active.

7500

Unlawful interference

Simulated ATC acknowledgement. When airborne, two visual-only F-15s approach if the aircraft model is installed separately.

7600

Radio communications failure

Simulated ATC recognizes the radio-failure code and points to FlightGear’s lost-communications procedure.

7700

General emergency

Simulated ATC acknowledges the emergency and prompts for its nature and your intentions, if able.

Simulator only. These acknowledgements are for FlightGear gameplay and are not operational aviation guidance or a substitute for real ATC procedures.

Installation

Three steps to the tower.

The package includes a RedGriffinATC directory that FlightGear can load as an add-on.

Download and extract

Unpack the ZIP or TAR.GZ archive. Keep the RedGriffinATC folder together.

Add the module folder

In FlightGear Launcher, open Add-ons, then add the extracted RedGriffinATC directory.

Enable and fly

Check that Red Griffin ATC is enabled, then start FlightGear. Open its menu item or press \.

For command-line starts, use --addon=/path/to/RedGriffinATC. The optional F-15 escort needs a separate FlightGear F-15 installation. Read the full README and controls ↗ for configuration and compatibility notes.
